## Visual review

Dashboard retains authoritative metrics and onboarding while smaller headers/rows and earlier two-column desktop grouping improve scanability. Users replaces profile-style rows with an access/status table and a narrower form; narrow screens stack safely. Secrets uses the same compact table vocabulary with explicit masking and small destructive controls. Settings separates preference, health rows and runtime facts without nested decorative cards. Light retains stone/ivory surfaces; Dark retains charcoal layers. Existing palette/tokens, focus and semantic colors are preserved.

The set was inspected before finalization. No page-level overflow was observed at 760×900; desktop was checked at the default viewport and 1440×900. No simulated screenshot, fake Run or generated UI image is evidence.
